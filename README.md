# Ascend Digital

Site institucional da **Ascend Digital** — automação de processos, dashboards de KPI e
desenvolvimento de sites.

Este repositório tem duas pastas:

| Pasta | O que tem |
|---|---|
| **`Codigo/`** | O projeto rodável (Vite + React + TS). É a **Root Directory** na Vercel. Veja `Codigo/README.md`. |
| **`Documentos/`** | README completo do projeto, `DATALOG.md` (histórico de alterações), brief do Canva, guia de deploy e o plano da reorganização. Comece por `Documentos/README.md`. |

## Começar

```bash
cd Codigo
npm install
npm run dev        # http://localhost:8080
```

## Deploy

Vercel, com **Root Directory = `Codigo`**. Passo a passo em `Documentos/deploy.md`.
